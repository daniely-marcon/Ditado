# Ditado 📝🦉

Um aplicativo móvel educativo focado no aprendizado e prática de ortografia através de ditados interativos. O projeto utiliza diferentes categorias da fauna para ensinar e testar os usuários de forma lúdica e visual.

## 📱 Visão Geral do Projeto

A concepção inicial deste aplicativo utilizou técnicas de prototipagem rápida.A criação de protótipos de baixa fidelidade (wireframes desenhados à mão) serviu como uma versão inicial para estudar e validar as alternativas de interface do usuário antes do início da codificação.Essa prática ajuda na validação dos requisitos e na redução de riscos na construção do sistema.

## ✨ Funcionalidades Principais

O aplicativo é estruturado em três telas principais:

* **Menu Principal (Categorias):** Tela inicial onde o usuário pode escolher qual grupo de animais deseja praticar. As categorias desenhadas incluem:
    * Aves
    * Peixes
    * Répteis
    * Anfíbios
* **Tela de Jogo (O Ditado):** A interface interativa de aprendizado que contém:
    * Uma imagem ou ilustração do animal selecionado.
    * Um botão de áudio (ícone de som) para ouvir a pronúncia/dica da palavra.
    * Campos de texto para o usuário digitar a resposta.
    * Botão de confirmação ("Tudo Certo") para submeter e validar a tentativa.
* **Tela de Progresso:**
    * Aba "Palavras Aprendidas", acompanhada de gráficos de desempenho para que o usuário possa visualizar sua evolução no aplicativo.

## 🚀 Como Executar o Projeto

    ```bash

    ```
2.  Abra o projeto no **Android Studio**.
3.  Aguarde a sincronização do Gradle.
4.  Execute o aplicativo em um emulador ou dispositivo físico clicando em **Run**.
